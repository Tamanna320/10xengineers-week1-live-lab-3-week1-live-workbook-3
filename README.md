# Assessment 3 - Block 3: Prompting & New Features

## Time Limit: 10 minutes

## Your Task

Add a new feature using effective prompts.

## Instructions

1. Open this repo in Codespaces (or run locally)
   > 📖 Refer to "Student guide to use Continue as AI agent in Codespace.pdf" for setup instructions
2. Review the feature request in `TASKS.md`
3. Use AI Chat to implement - but be specific:
   - Write clear, constrained prompts
   - Specify what you DON'T want
   - Accept only what you need

> **Note:** Do NOT use the default GitHub Copilot Chat. Use Continue extension for AI Chat instead.

## Getting Started

```bash
python main.py
```

## What You Should Learn

- Writing effective prompts
- Constraining AI output
- Implementing features incrementally

**Clarity before speed. Tell AI what NOT to do.**
